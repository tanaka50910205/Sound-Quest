# おとみち

[SoundQuest（soundquest.jp）](https://soundquest.jp/) の「自由派音楽理論」を、すき間時間に1〜2分ずつ進めるスマホ向けのドリル。
並び・用語・考え方（禁則がない／どこまで進むかは自分で決める）は SoundQuest に合わせています。
問題文と解説はこのアプリのために書いたもので、くわしい解説と音源は各ユニットの「記事を読む」から本家で読む作りです。

## SoundQuest に合わせたところ

画面の作りは SoundQuest のサイトの部品に合わせています。

**個人利用のため、本家のロゴ・キャラクター・画像も表示しています。** 画像ファイルはこのリポジトリには入れておらず、`js/assets.js` に書いた soundquest.jp のURLから読み込みます（一度表示すれば `sw.js` が端末に保存し、オフラインでも出ます）。ロゴ・キャラクター・夜空の絵・つまみ・「Q」マーク・アイコンの著作権は SoundQuest（©yuta yoshimatsu）にあります。このアプリを人に配ったり公開したりはしないでください。

- **ヘッダー**：白いバー、右にメニュー。メニューは暗い全画面
- **トップ**：夜空の見出し「自由派音楽理論」と、5つの編の進み具合を示すミキサーのつまみ（INTRO / PRE / MELODY / CHORD / RHYTHM）
- **目次**：大きな編の見出し＋細線、章見出し、縦線でつながる頭文字つきの丸バッジ。ゲートウェイは赤い進入禁止マーク
- **ユニットのページ**：記事と同じ形。細い大見出し、グレーのタグ、黒枠の箱（レッスン一覧）、黒い帯の見出し、黄色マーカー、グレーの帯の「Check Point」、記事リンク、焦げ茶の Continue ボタン
- **問題**：黒帯の「Q1.」、目次箱ふうの選択肢、暗い音声プレーヤー、点で示す鍵盤図、タグふうの並べ替え札
- **答えたあと**：Check Point の帯で解説、結果は「まとめ」
- **色**：編ごとに 序論＝茶、準備編＝オレンジ、メロディ編＝水色、コード編＝黄、リズム編＝くすんだ緑
- **用語・考え方**：六つの基調和音、レラティヴ、クオリティ・チェンジ、二次ドミナントなど。禁則がない／どこまで進むかは自分で決める

デュオリンゴから借りたのは、続けるためのしくみ（連続日数・XP・まちがえた問題の出し直し・復習）だけです。

## ユニット

| 編 | ユニット |
| --- | --- |
| 序論 | 自由派音楽理論とは |
| 準備編 | 音を表す名前について／音階の仕組み／度数と音程／調(キー)と五度圏 |
| メロディ編 | 階名と半音の傾性／三つの短音階 |
| コード編 | 六つの基調和音／ディグリーネーム／スリーコードと代理コード／コードの機能とケーデンス／クオリティ・チェンジ／王道進行と文化の差／拡張と借用 |
| リズム編 | リズムの基本（ドラムの音で聞き取り） |

## しくみ

- **インプット → 問題**：各レッスンの最初に、そのレッスンで扱う内容を読んで・聴くカード（デモ音・鍵盤図つき）。問題は、そのレッスンまでに読んだ内容からだけ出る（レッスン1はインプット1の内容だけ、レッスン2は1〜2、レッスン3は1〜3）。一度読んだインプットは「読んだことがある → 問題へ」で飛ばせる
- **間違えたとき**：「インプットを見直す」でそのカードをその場で開ける。「本編を読む」でその問題に対応する SoundQuest の記事へ

- 1ユニット＝レッスン3つ（各6問）。2ユニット以上ある編は最後にゲートウェイ
- 問題は4種類：選ぶ／聴く（その場で音を鳴らす。毎回ランダム、「ゆっくり」再生つき）／鍵盤をタップ／札を並べる
- XP・連続日数・1日の目標。回数の制限はなく、いつでも何回でもレッスンできる
- まちがえた問題は最後にもう一度。「復習」タブで苦手な問題だけ、「聞き取りだけやる」で耳トレだけ
- iPhoneの「ホーム画面に追加」でアプリのように開ける。一度開けばオフラインでも動く
- 記録は端末の中（localStorage）だけに保存

## 動かし方

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

ビルド工程はなし（素のHTML/CSS/JS）。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `js/content.js` | **問題データ**（編・ユニット・記事リンク・ポイント・問題・聞き取りの生成） |
| `js/assets.js` | SoundQuest の画像のURL（ロゴ・キャラクター・つまみなど） |
| `js/audio.js` | 音（ピアノ風の音とドラム。Web Audio API、音源ファイルなし） |
| `js/app.js` | 画面と動き（目次・レッスン・ゲートウェイ・復習・記録） |
| `css/style.css` | 見た目 |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面に追加・オフライン用 |

## 問題の足し方（`js/content.js`）

```js
{ t: 'mcq',   q: '問題文', o: ['正解', 'はずれ', 'はずれ', 'はずれ'], ex: 'Check Point の文' }  // 1番目が正解
{ t: 'key',   q: 'Fコードを全部タップ', a: [65, 69, 72], ex: '' }   // MIDI番号。鍵盤は 60(ド)〜76(ミ)
{ t: 'order', q: '並べよう', tiles: ['F', 'G', 'Em', 'Am'], extra: ['C'], ex: '' }
'triadMM'                                                          // 聞き取りは GEN の名前
```

内容の並びと用語は SoundQuest（©yuta yoshimatsu）の自由派音楽理論に沿っています。
