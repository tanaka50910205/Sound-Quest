# おとみち

すき間時間に1〜2分で、音楽理論と耳トレを少しずつ進めるスマホ向けWebアプリ。
扱う範囲は [SoundQuest（soundquest.jp）](https://soundquest.jp/) の流れを参考にしています（問題文と解説はこのアプリのために書いたものです）。

## できること

- **10ユニット × 4ステップ**（レッスン3つ＋まとめテスト）の道を、上から順に進める
  1. 音の名前と鍵盤　2. メジャースケール　3. 音程　4. 三和音　5. ダイアトニックコード
  6. コードの役割　7. 定番のコード進行　8. セブンスコード　9. マイナーキー　10. キーの外のコード
- 問題は4種類
  - 選んで答える（4択）
  - 聞いて答える（その場で音を鳴らす耳トレ。毎回ランダム、「ゆっくり」再生つき）
  - 鍵盤で答える（ピアノをタップ。和音は全部の音を押す）
  - 並べて答える（全全半… や コード進行を札で並べる）
- XP・連続日数・1日の目標（20/30/50XP）・ハート（まちがえると減る。20分で1つ回復）
- まちがえた問題は最後にもう一度出る。「復習」タブで苦手な問題だけをやり直せる（クリアでハートが1つ戻る）
- 各ユニットの「ポイント」で、3行の要点を先に読める
- 記録タブ：7日間のXP、ユニットの進み具合、音量・画面の明るさ・目標の設定
- iPhoneの「ホーム画面に追加」で、アプリのように全画面で開ける。一度開けばオフラインでも動く
- 記録は端末の中（localStorage）に保存。サーバーは使わない

## 使い方（ローカル）

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

ビルド工程はなし。素のHTML/CSS/JSだけ。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 入口 |
| `css/style.css` | 見た目（色・余白・箔のトロフィーなど） |
| `js/content.js` | **問題データ**。問題を増やすときはここだけ書きかえる |
| `js/audio.js` | 音を鳴らす部分（Web Audio API。音源ファイルなし） |
| `js/app.js` | 画面と動き（道・レッスン・復習・記録） |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面に追加・オフライン用 |

## 問題の足し方（`js/content.js`）

```js
{ t: 'mcq',   q: '問題文', o: ['正解', 'はずれ', 'はずれ', 'はずれ'], ex: '解説' }   // 1番目が正解。表示時にシャッフル
{ t: 'key',   q: 'Fコードを全部タップ', a: [65, 69, 72], ex: '解説' }              // MIDI番号。鍵盤は 60(ド)〜76(ミ)
{ t: 'order', q: '並べよう', tiles: ['F', 'G', 'Em', 'Am'], extra: ['C'], ex: '' } // tiles は正しい順で書く
'triadMM'                                                                          // 聞き取り問題は GEN の名前を書く
```

## デザインのきまり

- 田中ノートの「見た目」ルールに合わせた：スマホ前提／色分け多め／絵文字ではなく線アイコン（Lucide）／途中で切れるグラデーションは使わない
- ユニットの色は、ディグリー I〜VII に割り当てた7色を順番に使う
- クリアしたまとめテストとノーミスのメダルだけ、ホログラムの箔で光らせる
- 余白は4の倍数。タップできる所は高さ44px以上
- 見出しは Dela Gothic One、本文は Zen Kaku Gothic New
